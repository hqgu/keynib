安装

需要 Microsoft 365 版 Office（Mac / Windows / 网页版）。安装只是把一个几 KB 的清单文件交给 Office，面板本身是网页，更新自动生效。

Mac（一键安装）

  1. 打开「终端」（⌘ + 空格，输入"终端"），粘贴下面一行并回车： 
    curl -fsSL https://hqgu.github.io/keynib/install-mac.sh | bash
  2. 完全退出（⌘Q）并重新打开 PowerPoint / Word / Excel，在「开始」选项卡点击 妙笔助手。

若提示 macOS 隐私保护拦截，脚本会自动打开对应文件夹并把清单放在「下载」里，按住 ⌥ 拖进去即可。卸载：上面命令末尾加 -s -- --uninstall。

网页版 Office（任何电脑，包括 Windows）

  1. 下载清单：下载 manifest.xml
  2. 在浏览器打开 PowerPoint 网页版（Word、Excel 同理），新建或打开文档。
  3. 依次点击 开始 → 加载项 → 更多加载项 → 我的加载项 → 上传我的加载项，选择刚下载的文件。

Windows 桌面版

Windows 桌面版需要通过"受信任的加载项目录"（共享文件夹）侧载，步骤见微软官方说明：从网络共享文件夹侧载 Office 加载项。

我们尚未在 Windows 桌面版上实测，建议 Windows 用户先使用网页版；遇到问题请到 Issues 反馈。

开始使用

  1. 打开面板 → 右上角 ⚙ 设置 → 选择一家模型服务，填入你自己的 API Key → 拉取模型 → 测试连接（三项都打 ✓）→ 设为当前使用。
  2. PowerPoint、Word、Excel 的设置互不共享：在一个程序里点"生成配置码"（含 Key 时需设口令），到其他程序的设置页粘贴导入即可。
  3. 输入框开头输入 / 可调出快捷指令，如 /润色、/描述统计、/规范检查。
  4. 界面语言默认跟随 Office，可在设置最上方切换中文 / English。

English

Keynib is a bring-your-own-key AI assistant for Office: generate and lay out slides in PowerPoint, polish Word documents with tracked changes, and run formula-based analysis and charts in Excel. It works with multiple model providers and any OpenAI-compatible API. No server, no data collection (privacy).

Install

  • Mac: run curl -fsSL https://hqgu.github.io/keynib/install-mac.sh | bash in Terminal, then quit (⌘Q) and reopen Office and click Keynib on the Home tab.
  • Office on the web (any computer): download manifest.xml, then Home → Add-ins → More Add-ins → My Add-ins → Upload My Add-in.
  • Windows desktop: sideload via a network shared folder catalog (not yet tested by us; Office on the web is recommended for now).

Open the pane → ⚙ Settings → choose a provider, enter your API key → Fetch models → Test connection → Use this provider. Type / for commands.
