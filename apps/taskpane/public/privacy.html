隐私说明

妙笔 Keynib · 更新于 2026-11-22 · 返回首页 · English

一句话：妙笔没有服务器，不收集任何数据。它是一个运行在你的 Office 里的网页面板，你的文档内容和 API Key 只在你的电脑与你自己选择的服务之间传输。

数据去向

数据去向说明
API Key只保存在你的电脑（Office 面板的本地存储）可在设置中选择"仅本次使用"，关闭面板即清除；也可一键清除。导出"配置码"时含 Key 必须设口令加密。
文档内容（你让 AI 处理的部分）直接从你的电脑发送到你在设置中选择的大模型服务受该服务自身的隐私政策约束。处理机密资料时，可在设置中使用本地模型（自定义端点）。
文献检索词（作者、期刊、年份、主题词）美国国家医学图书馆 PubMed（NCBI E-utilities）仅在你开启"允许联网核对文献"后发送；不发送文档内容。默认关闭。
会话历史、设置、演示规范只保存在你的电脑可在设置中清除。不同 Office 程序之间不共享，可用配置码手动同步。
使用统计、错误日志不收集妙笔不含任何统计、分析或遥测代码。

网页托管

面板网页托管在 GitHub Pages（hqgu.github.io）。加载面板时，GitHub 可能按其隐私政策记录访问日志（如 IP 地址）。Office 加载面板所需的 office.js 由微软提供。

Privacy (English)

Keynib has no server and collects no data. It is a web pane running inside Office. Your document content and API keys travel only between your computer and the services you choose.

  • API keys are stored only on your computer (or for the current session only, if you choose). Config codes containing keys are passphrase-encrypted.
  • Document content you ask the AI to work on is sent directly from your computer to the model provider you selected, under that provider's privacy policy. For confidential material you can use a local model via a custom endpoint.
  • Citation search terms (author, journal, year, keywords) are sent to PubMed (NCBI) only if you enable citation checks. Document content is never sent. Off by default.
  • Chat history and settings stay on your computer.
  • No analytics or telemetry of any kind.
  • The pane is hosted on GitHub Pages, which may keep access logs per its own policy. Source code: github.com/hqgu/keynib (MIT).
