## 真机测试（Mac Word 16.112 + DeepSeek，空白测试文档，含一条模拟的"用户原有修订"）
| 场景 | 结果 |
|---|---|
| 润色第 2 段（3 处） | ✅ 修订为词句级（2 条），未整段重写；修订模式恢复 Off；用户原有修订保留 |
| 全部拒绝（修复前） | ❌ 正文丢字："替换"产生的 Deleted 条目在 Added 被拒绝后才出现，未被处理 |
| 全部拒绝（修复后） | ✅ 正文与润色前一字不差；用户原有修订保留；模式 Off |
| 润色 + 补一句 → 全部接受 | ✅ 3 条修订；接受后正文与接受前所见一致；用户原有修订保留；模式 Off |
