## 政策核实（微软商店，供以后上架参考）
- 1120.3：必须支持网页版 Office 与 Mac，兼容 Edge / Chrome / Firefox / Safari。
- 提交时须提供测试账号或说明，审核员不能先联系开发者 → BYOK 需提供限额测试 Key。
- 100.5 / 100.6：须有隐私政策、条款与支持页。
- 100.1.3 / 100.2.2：商店介绍中不得使用其他公司的商标或作为关键词（不能写 Claude、ChatGPT 等）；100.4 须披露对第三方服务的依赖。

## 网页版 Office 实测（Chrome，PowerPoint 网页版）
| 项 | 结果 |
|---|---|
| 以 localhost 开发版加载 | ❌ Chrome 拦截公网页面加载本机地址 → 改用 GitHub Pages 正式版 |
| 7 家直连 | ✅ 全部可达（77–973 ms） |
| 刷新后设置与 Key | ✅ 保留 |
| 存储跨宿主 | ✅ 网页版 PowerPoint 与 Word 互相可读（与 Mac 桌面版不同） |
| PowerPointApi | 1.10 |
| ⌘Z 撤销加载项写入 | ❌ 网页版不撤销 → "撤销本轮"在网页版更重要 |
| PPT 接口 | 首轮：新建页、读版式、导出 / 插回报 GeneralException；逐项探针：16 项中 15 项通过，唯一失败为按 ID 查找刚新建的幻灯片（`SlideCollection.getItem`） |
| 修复 | 定位幻灯片一律按序号（`getItemAt`）；只读工具与撤销快照遇 GeneralException 重试 2 次（写入不重试）。Mac 回归：探针 17/17、撤销自测 5/5、真实对话插页 + 撤销通过 |
| 缓存 | Pages 缓存 10 分钟，网页版面板不受 ⌘⇧R 影响 → 加自动更新 |
