# M3 进度：Excel 数据分析 + 图表（2026-11-22）

## 设计
- 结果、图表、透视表一律写到本轮新建的结果表（`create_output_sheet`）→ 撤销 = 删除本轮新建的表。
- 覆盖原有工作表 `overwrite_range` 为 D 级：需用户确认；执行前快照 formulas + numberFormat（≤ 5 万单元格），撤销时还原。
- M3 不在原有工作表上建表格、条件格式或改单元格格式（需格式快照，未实测）。
- **统计量必须是 Excel 公式**；`write_range` 写后回读，返回错误单元格（#DIV/0! 等）与 FILTER 含 0 的警告。
- 提示词：分析前先列 3–5 行分析计划（SAP）；FILTER 取数必须排除空白；中文表名加单引号。
- 快捷指令：/描述统计、/分组比较、/画图、/数据透视。

## 测试中发现并修复
1. **箱线图混入缺失值（统计错误）**：`FILTER(F, B="对照")` 把空白变成 0，两组分别混入 3、8 个 0。修复：提示词要求 `(F<>"")`；`write_range` 检测 FILTER 溢出结果含 0 时警告。复测：辅助列 90 / 99 个值，无 0。
2. numberFormat 尺寸与数据不一致导致整批写入失败 → 自动补齐。
3. 模型漏填 sheet 参数 → 本轮只新建一张表时自动使用。
修复后第三次运行：0 次工具失败，45 项全部匹配。

## 观察
- 两次破坏性操作测试（PPT 删页、Excel 覆盖）中，用户都在收到"请点跳过"的提示前点了醒目的主按钮"确认执行"。建议：确认卡片两个按钮同等权重，破坏性按钮写明动作（"确认删除 / 确认覆盖"）。
