# 开发指南（M0）

## 目录
```
apps/taskpane/        React + Fluent UI v9 任务窗格（对话 / 历史 / 设置 / 诊断）
  src/hosts/powerpoint/  PPT 工具集、撤销快照、系统提示词
packages/providers/   厂商预设、协议适配器（Anthropic / OpenAI 兼容）、直连探针
packages/core/        Agent 循环与权限
manifest/             manifest.dev.xml（PPT / Word / Excel 共用）
scripts/              sideload-mac.mjs、cors-preflight.mjs
docs/                 规划、探针报告
```
> 规划写的是 pnpm；本机未装 pnpm，M0 先用 npm workspaces，结构不变。

## 首次运行（Mac）
1. 安装依赖：`npm install`（若 `~/.npmrc` 中的代理未运行，可临时用 `npm install --no-proxy --no-https-proxy`）
2. 安装并信任本地 HTTPS 开发证书（会弹出钥匙串授权）：`npm run certs`
3. 启动开发服务器：`npm run dev` → https://localhost:3000/taskpane.html
4. 侧载清单：`npm run sideload:mac`
5. **完全退出**并重启 PowerPoint，打开任意演示文稿 → "开始"选项卡 → **妙笔助手**
   （若按钮未出现：开始 → 加载项 → 我的加载项 / 开发者加载项）
6. Word、Excel 同理。卸载侧载：`npm run sideload:mac -- --remove`

## 常用命令
| 命令 | 作用 |
|---|---|
| `npm test` | 单元测试（Node 原生 test runner） |
| `npm run typecheck` | TypeScript 类型检查 |
| `npm run validate` | 校验清单 |
| `npm run probe:cors` | 服务器侧 CORS 预检（不需要 Office） |
| `npm run build` | 构建静态站点到 `apps/taskpane/dist` |

## M0 诊断面板怎么用
1. PowerPoint 中依次运行：浏览器直连探针 → 存储共享探针 → PPT 往返探针 → 撤销探针。
2. 打开 Word、Excel，各自再点一次"存储共享探针"和"撤销探针"。
3. 每个宿主点"复制报告"，把 JSON 发回，用于填写 `docs/M0-探针报告.md`。
